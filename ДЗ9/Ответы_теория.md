# Ответы на задачи 1-3

## Задача 1

а) В JSON попадут только Name и Score:

```json
{"Name":"Alex","Score":100}
```

Name и Score — публичные свойства, поэтому сериализуются. secretCode не попадает, потому что это private-поле. IsAlive не попадает, потому что это поле, а System.Text.Json по умолчанию сериализует только свойства.

б) Заменить поле на свойство с публичным геттером и приватным сеттером:

```csharp
public int SecretCode { get; private set; } = 42;
```

Сериализация идёт через геттер, значение попадёт в JSON, а снаружи поле по-прежнему нельзя изменить.

в) IsAlive не попадает, потому что это поле, а не свойство. Два способа исправить:

1. Превратить поле в свойство:

```csharp
public bool IsAlive { get; set; }
```

2. Поставить атрибут [JsonInclude] на поле:

```csharp
[JsonInclude]
public bool IsAlive;
```

## Задача 2

а)

```csharp
public class Game
{
    public string Title { get; set; }
    public int Year { get; set; }
    public double Rating { get; set; }
    public string[] Genres { get; set; }
    public bool IsMultiplayer { get; set; }
}
```

б) System.Text.Json сопоставляет ключи JSON со свойствами с учётом регистра, поэтому "title" не сопоставляется со свойством Title и остаётся null. Решение без переименования свойств:

```csharp
var options = new JsonSerializerOptions { PropertyNameCaseInsensitive = true };
Game game = JsonSerializer.Deserialize<Game>(json, options);
```

в) Да, строка валидная — это массив с элементами разных типов. В строго типизированный массив (int[], string[]) он не десериализуется, подходят JsonElement или object[]:

```csharp
JsonElement array = JsonSerializer.Deserialize<JsonElement>(json);
object[] items = JsonSerializer.Deserialize<object[]>(json);
```

## Задача 3

1. File (File.ReadAllText) — файл маленький, читается целиком одним вызовом.
2. File (File.WriteAllText) — состояние целиком перезаписывается при каждом автосохранении.
3. FileStream (FileMode.Append) — поток открывается один раз в режиме дозаписи, файл на гигабайты не перечитывается.
4. File (File.Exists + File.ReadAllText) — проверка существования и чтение целиком, обе операции из класса File.
5. FileStream (FileMode.Open, Seek + Write) — нужен произвольный доступ: переход на позицию в середине файла и перезапись только нужных 10 байт.
